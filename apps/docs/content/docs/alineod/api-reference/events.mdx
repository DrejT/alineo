```bash
curl -N localhost:4600/runs/r_3f9a1c20/events
```

`GET /runs/:runId/events` is a Server-Sent Events stream carrying the entire run: alineod's own lifecycle events
and the harness events of every agent in the run. Every event's `data` is JSON with an `agentId` field (`null` for
run-level events).

```
id: 7
event: agent.steered
data: {"agentId":"a_c01d9e3a","message":"Focus only on src/auth."}
```

## Lifecycle events

These are always persisted to the ledger and carry an `id`.

| Event                 | Fields                                                                                        | When                                                                                                                                |
| --------------------- | --------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `run.started`         | `runId`                                                                                       | A run is created.                                                                                                                   |
| `agent.spawned`       | `parentAgentId`, `runId`, `specName`, `depth`, `spawnIndex`, `sandboxId`, `waitFor`, `prompt` | An agent is accepted. `sandboxId` is `null` until provisioned.                                                                      |
| `agent.provisioned`   | `sandboxId`                                                                                   | The agent's sandbox exists and its harness is reachable.                                                                            |
| `agent.state_changed` | `from`, `to`, `reason`, `pausedBy`                                                            | A state transition, e.g. `spawning → provisioning` (`deps-settled`) or `running → paused` (`operator`).                             |
| `agent.steered`       | `message`, `scope`, `roster`, `deliveredAs`                                                   | A steer message was accepted. `roster` and `deliveredAs` are set for a subtree steer.                                               |
| `handle.settled`      | `outcome`, `resultRef`                                                                        | The agent's result is available.                                                                                                    |
| `agent.ended`         | `outcome`, `endedAt`, `error`                                                                 | The agent finished, failed, was stopped, or was lost.                                                                               |
| `budget.denied`       | `dimension` (`spawnDepth` \| `maxAgents`), `remaining`                                        | A spawn under this agent was refused by a budget.                                                                                   |
| `agent.released`      | `reason`                                                                                      | A finished agent's open sandbox was closed (stop / delete), or a fork landed after its spawn was stopped. Its outcome is unchanged. |
| `wait.resolved`       | `mode`, `outcome`, `selected`, `settled`, `pending`                                           | A held spawn's `waitFor` resolved. `depfail` / `deadline` end the child without forking.                                            |
| `wait.blocked`        | `blockedOn`                                                                                   | A held spawn is still waiting on a dependency that's paused.                                                                        |
| `run.quiescent`       | `memberCount`, `asOf`                                                                         | The subtree rooted at this agent just finished, while someone was waiting on it.                                                    |
| `notify.registered`   | `on`, `wake`                                                                                  | This agent subscribed to be told when the agents in `on` finish.                                                                    |
| `inbox.queued`        | `kind`, `aboutAgentId`, `outcome`, `resultRef`, `excerpt`, `again`, `text`                    | A notification (or a queued subtree steer) is waiting for this agent.                                                               |
| `inbox.delivered`     | `seqs`, `as` (`steer` \| `turn` \| `prompt`)                                                  | Queued items were delivered.                                                                                                        |
| `inbox.dropped`       | `seqs`, `reason`                                                                              | Queued items were dropped because the recipient closed.                                                                             |

## Harness events

Each agent's stream events (the SDK's [`AgentEvent`](/docs/agent/getting-started/streaming)) are forwarded onto
the run stream under their own type names, tagged with the `agentId` that produced them.

**Persisted** — carry an `id` and are replayed on reconnect:

`session.started`, `session.ended`, `turn.started`, `turn.ended`, `tool.started`, `tool.ended`, `compaction.started`,
`compaction.ended`, `permission.requested`, `permission.resolved`, `retry.started`, `retry.ended`,
`extension.error`

**Ephemeral** — no `id`, never replayed: everything else, including high-volume `message.updated` deltas and `tool.updated`.

## Reconnecting

Send the last `id` you received as `Last-Event-ID`:

```bash
curl -N localhost:4600/runs/r_3f9a1c20/events -H 'Last-Event-ID: 128'
```

alineod replays every persisted event after that `seq` from the ledger, then switches to live events. Ephemeral
events emitted while you were disconnected are lost; persisted events are not.

To start from a known snapshot, read `GET /runs/:runId` and use its `asOf` as `Last-Event-ID`.

## Heartbeats

A comment line is sent every 10 seconds so proxies and clients don't treat a quiet run as a dead connection.

## Slow consumers

If a client stops reading, alineod drops ephemeral events for that connection first. If it falls behind by 500
persisted events in a row, the connection is closed — reconnect with `Last-Event-ID` to continue with nothing
missed.
