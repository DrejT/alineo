`alineo` runs an AI coding agent inside a sandbox container. An agent is a spec and a prompt:

```ts
import { Alineo, textOnly } from "alineo";
import { SQLiteAdapter } from "@alineo-labs/sqlite";

const agent = await Alineo.load(
  {
    name: "hello",
    cli: "pi",
    provider: "nvidia",
    model: "nvidia/nemotron-3.5-lightning-30b-a3b",
    env: { NVIDIA_API_KEY: "${NVIDIA_API_KEY}" },
  },
  { adapter: new SQLiteAdapter("./.alineo/ledger.db") },
);

for await (const chunk of textOnly(agent.prompt("Write and run a Python hello world."))) {
  process.stdout.write(chunk);
}
```

The agent installs packages, clones repositories and runs what it writes — inside the container,
never on your machine. [Quickstart →](/docs/agent/quickstart)

## It starts in seconds

The first `load()` installs the [Pi](https://pi.ai) CLI into a `node:22` sandbox and checkpoints
it. Every load after that restores the snapshot instead: **~3 seconds rather than ~90**. The cache
key is the spec's packages, setup steps and CLI version, so it invalidates itself when it should —
[snapshots and fast starts](/docs/agent/concepts/snapshots).

## Your process is not the agent

The agent lives in the container, not in your Node process. Kill the process, come back tomorrow,
pick the same agent back up:

```ts
const agent = await Alineo.reattach(sandboxId, { adapter });
```

Pi restarts with `--continue`, so the session it was in the middle of is still there.

## Steer it mid-turn

```ts
await agent.steer("Focus only on the auth path — drop the unrelated findings.");
```

The message lands after the current tool call finishes and before the next model call. The agent
does not restart and does not lose its context. `pause()` freezes the container outright;
`resume()` continues from the same instruction — [steering and pausing](/docs/agent/concepts/steering).

## Gate what it can do

Every tool call the agent wants to make can be held for a decision — yours, or a policy's:

```ts
agent.prompt(task, {
  onPermission: (req) =>
    req.tool === "bash" && req.target.startsWith("rm ")
      ? { kind: "reject", feedback: "Deleting files is out of scope." }
      : { kind: "once" },
});
```

`reject` hands the feedback back to the model as the reason. Leave `onPermission` off and the
requests surface on the stream instead, for a human to resolve with `agent.resolvePermission()` —
[the permission gate](/docs/agent/concepts/permissions).

## Fork a running agent

```ts
const reviewer = await agent.spawn("./agents/reviewer.json");
```

The child is forked from the parent's **live** sandbox — the checkout, the installed packages, the
files the parent wrote are already on its disk. Clone a repository once and review it three ways at
the same time.

For more than a couple of children — budgets, `waitFor` gathering, one event stream for the whole
tree, recovery when the host dies — that's [alineod](/docs/alineod), which drives this SDK
in-process and exposes it over HTTP.
