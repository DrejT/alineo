Docs site only, no publishable package changes: cut `content/docs/{core,alineo}/v0.3`
now that `@alineo-labs/core@0.3.0` / `alineo-cli@0.1.4` are published to npm. The
credential-injection docs (#204) were written in place into the then-latest `v0.2`
folder before 0.3.0 shipped — so `v0.2` was silently describing 0.3.0's API and the
unversioned aliases (`/docs/core`, `/docs/alineo`, `/`) still redirected to `0.2`.
`v0.3` is a copy of `v0.2` with its internal links repointed to `0.3`; the version
registry, redirects, and switcher (`source.config.ts`, `src/lib/source.ts`,
`public/_redirects`) are regenerated by `predev`/`prebuild` from the new folders,
with `0.3` now marked latest. `v0.2` stays on disk as a frozen snapshot.
