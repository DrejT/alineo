New package: `alineo-mcp`, an MCP (Model Context Protocol) server exposing alineod's swarm-control HTTP + SSE API — creating runs, spawning/prompting/steering/pausing/stopping agents, watching live events, resolving results — plus local agent-spec management (`add`/`list`/`remove`) and a Docker bootstrap (`init`), as tools any MCP client (Claude Code, Claude Desktop, Cursor, …) can invoke.
